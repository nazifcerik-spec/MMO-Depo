# CLAUDE.md

Bu dosya Claude Code oturumları için proje kılavuzudur.

## Proje

**MeNa World** (eski adı New World MMO, DD-270; kod adı **Otter**, DD-228) — Persistent Idle MMORPG. Flutter (client) + Go (server) + PostgreSQL + Redis.

Tasarım Faz 00'da tamamlandı; şu an **Faz 01: Implementation** aktif.

## Dizin

- `docs/` — Faz 00 tasarım katmanı. **Kanonik referans.** Her uygulama kararı burada bir DD ile eşleşmeli.
- `server/` — Go application server.
- `client/` — Flutter client (mobile-first; Android/iOS/web).
- `deploy/` — docker-compose dev + prod Dockerfile.
- `scripts/` — Yardımcı script.

## Kritik Kurallar (Faz 00 → Faz 01 taşınan)

1. **Server-authoritative.** Client input her zaman doğrulanır. Bkz. [docs/security/](docs/security/).
2. **Ledger-first (DD-135).** Değer transferi yalnızca `TxnService.Write` üzerinden; double-entry sum=0; SERIALIZABLE. Hiçbir domain wallet/balance sütununa direkt UPDATE yazmaz.
3. **AFK analytical, tick simulation değil (DD-084).** Reveal O(1) Poisson/Binomial sampler + linear inverse threshold.
4. **Idempotent by default (DD-188).** Mutating endpoint'ler `idempotency_key` zorunlu; `api.idempotency_record` 24h.
5. **Correlation ID her yerde (DD-205).** HTTP → domain → log → audit. `X-Request-Id` inbound, yoksa server generate.
6. **Config env var (12-factor).** Secret repo'ya girmez.
7. **Structured JSON log** stdout; PII redact (Bearer token, email masked).
8. **Test deterministik.** RNG seed injection, clock injection. Flaky → root cause fix, retry değil.

## Kod Konvansiyonları

- Go 1.26+ (`go.mod`); derleme/CI Go 1.27 son yama (DD-237). `log/slog` stdlib logger.
- Router: `chi` (thin).
- DB: `pgx/v5` (native, no ORM).
- Redis: `go-redis/v9`.
- UUID: `google/uuid` (v4 default; audit için opsiyonel v7).
- Config: `kelseyhightower/envconfig`.
- Tests: `testing` + `testify/require`; integration testcontainers-go.
- Error: sentinel error + wrap (`fmt.Errorf("...: %w", err)`); HTTP handler'da domain error → HTTP status map.
- Package layout: `internal/domain/<name>` self-contained (repo interface + service + http handlers).
